##### Information about "hi-env-dir" and "hi-env-omni" simulation sets
These sets use a repeating spiral path type where each spiral is rotationally offset to create greater angular and distance coverage within a 3D field of interest.
- Flight layers are recorded over 10 meter intervals over 90 meters, from 5 to 95 meters,
- We use a omnidirectional antenna for one set and a directional antenna for another.
- We apply simulated environment noise to both sets to mimic real world datasets.
